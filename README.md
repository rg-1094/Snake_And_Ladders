# Snakes and Ladders v1.1

Snakes and Ladders v1.1 enhances the classic desktop game with hop-by-hop token animations, realistic snakes and ladders, plus retro sound. Supports 1 to 4 local players or CPU rivals, featuring exact-finish rules, dynamic token offsets, and an action log. Enjoy smooth, portable, and install-free retro gaming on any modern Windows desktop computer.
